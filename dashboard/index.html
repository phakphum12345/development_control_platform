Development navigation

Colors indicate the type of activity, not permission to perform it.

01 · READInspect repository, branch, commit and working tree. 02 · ANALYZEReview diffs, requirements, gate results and SHA binding. 03 · WRITE / MODIFYConfirm target and authorized file scope before editing. 04 · TESTRun checks and capture evidence for the exact commit. 05 · AUDITReview permissions, evidence freshness and Git history. STOP · BLOCKStop if the target, permissions or commit identity mismatch.

READ Confirm the target

  • Repository: not connected in this preview.
  • Branch and full commit SHA: must be verified from the actual repository.
  • Registered projects: 0.

ANALYZE Verify before acting

  • Compare staged and unstaged changes separately.
  • Confirm the intended repository, branch, files and approved scope.
  • Reject missing, stale, mismatched or unverifiable evidence.

WRITE Explicit scope only

This preview provides no write action. Color, navigation or project selection never grants write permission.

  • Keep integrations disabled by default.
  • Require explicit approval for new write scopes.
  • Do not force-push or rewrite canonical history.

UNKNOWN Test evidence

No live test results are loaded. A green indicator must only be used after a real check passes against the exact intended commit SHA.

AUDIT

  • Review the full diff and file inventory.
  • Verify the source, freshness and commit identity of evidence.
  • Confirm all required gates pass before any merge decision.

BLOCK Stop conditions

  • Repository or branch does not match the approved target.
  • Evidence SHA differs from the project commit SHA.
  • A required gate is missing or not passing.
  • Write permission or external connection has not been explicitly authorized.
